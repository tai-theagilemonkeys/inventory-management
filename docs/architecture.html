Frontend
Vue 3

Backend
FastAPI
Python, Pydantic models, uvicorn server, port 8001. CORS open to all origins (dev only).

JSON files
server/data/*.json loaded into memory at startup via mock_data.py — no database.

Axios

Request / Data Flow

1

User adjusts a filter

Time Period, Warehouse, Category, or Order Status changes update the shared refs in useFilters.js. Because these are module-level singletons, every view reads the same selection.

2

View calls the API client

A view's loadData() calls api.getX(getCurrentFilters()), which builds a query string and issues an Axios GET to http://localhost:8001/api/....

3

FastAPI filters in memory

The route handler applies warehouse / category / status / month filters (skipping any set to "all") directly against the in-memory Python lists — no query planner, no indexes.

4

Pydantic validates the response

Filtered results are returned through a typed response_model, guaranteeing shape before serialization back to JSON.

5

Vue stores raw data, derives the rest

Responses land in raw refs (e.g. allOrders, inventoryItems); everything the template renders — totals, charts, groupings — comes from computed() properties layered on top.
